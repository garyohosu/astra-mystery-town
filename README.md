# Astra Mystery Town

Astraによる3D推理ゲーム制作実験「消えた町長と、五人の証言」。

## 方針
- ソースと制作記録はこのリポジトリで管理する。
- 配信先はChatGPT Sites。
- プレイ中のAI API・CLI呼び出しは使用しない。
- 初版は昼の町。夜と懐中電灯への変更は、初版完成後の別課題とする。
- 成果を事前に成功扱いせず、検証済み事項と未検証事項を区別する。

## 現在の版
夜の町と懐中電灯を実装。Fキーまたは「懐中電灯」ボタンで点灯・消灯、Q・Rで照射方向を変更する。初版の昼の町はGit履歴に保存している。検証範囲と未確認事項は `docs/experiment.md` を参照。
